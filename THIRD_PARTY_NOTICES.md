# Tredjepartsmaterial

Listan omfattar material som ingår i repot eller som den planerade appen ska innehålla. Den uppdateras när materialet läggs till, och licenstexterna följer med i så fall i repot.

| Material | Användning | Licens |
|---|---|---|
| [Nunito](https://fonts.google.com/specimen/Nunito) | Typsnitt, variabel TTF från github.com/google/fonts (`ofl/nunito`, hämtad 2026-11-06), i `iOS/Packages/SophamtningKit/Sources/SophamtningDesign/Resources/Fonts/` | SIL Open Font License 1.1 |
| [Fredoka](https://fonts.google.com/specimen/Fredoka) | Typsnitt, variabel TTF från github.com/google/fonts (`ofl/fredoka`, hämtad 2026-11-06), i samma katalog | SIL Open Font License 1.1 |
| [Lucide](https://lucide.dev) | Fraktionsikoner (SVG), `lucide-static` version 1.70.0 från unpkg.com, i `Resources/Icons.xcassets/`. Licensen ligger i `Resources/Icons/LICENSE-Lucide.txt` | ISC |
| [Wikidata](https://www.wikidata.org) | Lista över orter och kommuner | CC0 |
| [Sopor](https://github.com/jesperhardyson/sopor) | Startdesign och ortlistans format | MIT |

Uppgifterna om tömningar kommer via Sopor API från respektive kommun eller avfallsbolag och ingår inte i repot.
